###Computer science
#How does computer interpret the data we give it to solve problems, understand what gave to give us an output?
Computers use transistors ( a tiny semiconductor device used to amplify or switch electrical signals and power) so it can interpret and understand what we input through only 0s and 1s. This 0s and 1s are called binary code and also know as machine language. But to make the computers understand more and with less computational power people came up with ASCII values which are exactly are stored in 8-bit bytes (eg: 01001110) (8-bit = 1 byte).
