#How does computer interpret the data we give it to solve problems, understand what gave to give us an output?
Computers use transistors ( a tiny semiconductor device used to amplify or switch electrical signals and power) which can help interpreting and understanding what we input through only 0s and 1s. This 0s and 1s are called binary code and also know as machine language. But to make the computers understand more and with less computational power people came up with ASCII values which are exactly are stored in 8-bit (eg: 01001110) (8-bit = 1 byte).

##ASCII (American Standard Code for Information Interchange)
Since there is an overlap between the ones and zeros that represents numbers and letters, the ASCII standard was created to map specific letters and specific numbers and ASCII uses only 128 of those (0-127) in 256 distinct machine codes in 8-bit.

##Unicode
-Since there are not enough digits in binary to represent all various characters that could be represented and understood by humans, the Unicode standard expanded the numbers of bits (eg: 32bits, 64bits) that can be transmitted and understood by computers. Unicode doesn't only consist special characters but all emoji.
-The pattern of 0s and 1s are standardized by Unicode, but the graphics design of these emoji can be modified and represented as the device manufacturer wants.

##RGB
-Zeros and ones can be used to represent color. RGB is a combination of Red, green and  Blue with these RGB values computers can represent images, videos and music.
